# QazTender AI 0.3

Бесплатный двуязычный интерфейс для поиска официальных объявлений о государственных закупках Казахстана.

## Источник данных

Проект использует унифицированные сервисы Портала государственных закупок РК:

- объявления: `https://ows.goszakup.gov.kz/trd-buy/all`;
- способы закупки: `https://ows.goszakup.gov.kz/refs/ref_trade_methods`;
- статусы объявлений: `https://ows.goszakup.gov.kz/refs/ref_buy_status`.

Официальный API требует Bearer-токен. Согласно документации, разработчику нужно обратиться в Министерство финансов Республики Казахстан и запросить доступ к унифицированным сервисам.

Пример текста обращения:

> Просим предоставить доступ к унифицированным сервисам Портала государственных закупок и выпустить токен авторизации. Данные планируется использовать в QazTender AI для отображения публичных объявлений о государственных закупках.

## Как безопасно добавить токен

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Secrets and variables → Actions**.
3. Нажмите **New repository secret**.
4. Имя секрета: `GOSZAKUP_API_TOKEN`.
5. Вставьте полученный токен как значение и сохраните.
6. Откройте **Actions → Sync official procurement data → Run workflow**.

Токен нельзя добавлять в `index.html`, JavaScript сайта, `README.md`, Issues или коммиты. GitHub Actions использует секрет только на сервере, сохраняет в `data/tenders.json` очищенные публичные поля и не публикует сам токен.

## Обновление

После настройки секрета данные обновляются автоматически каждые шесть часов. Сайт размещён бесплатно через GitHub Pages. Пока токен не настроен, сайт показывает честное пустое состояние и не подменяет официальные данные демонстрационными закупками.
